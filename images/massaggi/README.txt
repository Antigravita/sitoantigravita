CARTELLA IMMAGINI — PAGINE MASSAGGI
===================================

Metti qui un'immagine per ogni tipo di massaggio.

Convenzione nomi (nome file = slug della pagina), formato libero (.png/.jpg/.webp):

  olistico-trieste.(png|jpg|webp)
  decontratturante-trieste.(png|jpg|webp)
  pietre-calde-trieste.(png|jpg|webp)
  fly-massage-trieste.(png|jpg|webp)

Dimensione consigliata: orizzontale ~1200x800 (3:2), foto SENZA testo sopra
(il titolo è gia testo HTML). Peso non importa: vengono compresse in automatico.

Quando aggiungi un file con il nome giusto, vengono:
  1) convertite in .webp leggero
  2) cancellato l'originale pesante
  3) collegate sia alla pagina del massaggio sia alla card nella hub
     (/massaggi-trieste)

Stesso identico flusso usato per le immagini del blog (/images/blog/).
